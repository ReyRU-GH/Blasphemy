# Deep Torment - Terraria Mod

ENGLISH | [РУССКИЙ](#русский)

## FEATURES
- New enemies and bosses
- Unique weapons and items  
- Challenging gameplay mechanics

## INSTALLATION
1. Install tModLoader from Steam
2. Download the latest .tmod file from Releases
3. Place in Documents/My Games/Terraria/ModLoader/Mods/
4. Enable in tModLoader

## DEVELOPMENT
Requires tModLoader and Visual Studio.
